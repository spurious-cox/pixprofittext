Icons are built with one shared script, for every PixPro app:

    pixpro_icon FitText

It takes the master from ~/Pictures/Pixelmator/PixProStuff/PixProIcons/ and
places it on Apple's 824-in-1024 grid. To change the icon, replace the master
there and run that command.

The per-app builder here is retired; rebuilding this way is byte-identical to
the icon the installed app carries.
